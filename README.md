# ⏱️ Pomodoro Timer (Redux Version)

A Redux-powered Pomodoro Timer app built with React. It helps you stay focused using the Pomodoro Technique by timing your work and break sessions. This version uses **Redux Toolkit** for state management and is intended for local use or future deployment.

---

## 🌟 Features

- ⏰ Work & break timers with customizable durations  
- 🔁 Automatically tracks completed Pomodoro cycles  
- 🎨 Toggle between Light ☀️ and Dusky 🌙 themes  
- 💾 Saves theme and cycle count using LocalStorage  
- 🧠 Powered by Redux Toolkit  

---

## 🛠️ Tech Stack

- **React** – Frontend  
- **Redux Toolkit** – State management  
- **LocalStorage** – To persist user preferences (theme & cycles)
